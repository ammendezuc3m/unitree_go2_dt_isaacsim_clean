# Unitree Go2 Digital Twin with Isaac Sim

This repository contains the updated demo code and assets for a Unitree Go2 digital twin integrated with Isaac Sim, ROS 2, 60 GHz sensing/communication experiments, CSI inference, camera-based perception, LiDAR state reading, and Raspi/no-Raspi demo modes.

## Main folders

- `go2_dt/`: demo scripts, ROS 2 workspace, perception/sensing modules, networking scripts and experiment launchers.
- `go2_assets/`: Isaac Sim USD assets and demo scenario resources.

Detailed setup and execution instructions will be added progressively.
